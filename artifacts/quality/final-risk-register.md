| Residual risk | Evidence and interpretation | Mitigation / boundary |
| --- | --- | --- |
| Browser performance varies with page warm-up and Orca workspace visibility. | Cold input pilots moved by several milliseconds, and a hidden Orca worktree throttled playback toward 1 Hz. This is an environment effect, not evidence of a telemetry hot-path call; the raw failed pilots are retained. | The deciding run activated the worktree, used fixed warm-up, balanced order, and an input tab crossover. Both p95 gates passed with no long tasks or structural rebuilds. Re-run the same warmed protocol when changing telemetry or Foundry rendering. |
| The Orca embedded browser runs Foundry playback near 12 fps in this desktop configuration. | Absolute frame intervals are not representative of every classroom Chromebook or Tauri GPU. The off/on comparison is internally controlled and the production browser suite separately validates cadence and rebuild bounds. | Treat the A/B result as a regression comparison, not a universal FPS claim. Profile representative classroom hardware before changing device support claims. |
| ONNX Long Task API checks are sensitive to concurrent Chromium host contention. | The strict G5 threshold passed in isolation; controlled concurrent copies reproduced spurious overlap. The final main browser project remained parallel with two workers, then the dedicated performance project ran once after it. | Keep the strict threshold and the isolated `chromium-performance` dependency. Do not weaken the assertion or serialize the functional suite. Raw contention and isolated logs are preserved. |
| Study delivery is deliberately best effort. | The runtime has one normal attempt and one exit-beacon attempt, with no retry, queue, durable outbox, or persisted identity. Network loss can produce missing sessions or partial populations. | The analyzer reports missing sessions/fields and explicit denominators. Never claim complete delivery, workflow reconstruction, or causal attribution. |
| Enabled payloads still expose coarse device context. | Viewport, hardware-concurrency, pointer, and network values are fixed buckets, not raw browser fingerprints. No identity, project state, geometry, path, filename, URL, free text, image, or action stream is accepted. | Preserve the exact schema allowlist, 8,192-byte cap, compile-time profile boundary, omitted credentials, and no-referrer transport. Require a new privacy review before adding any field. |
| Native packaging and external deployment were not exercised. | `bun run build:tauri-frontend` passed, and release/version/workflow contracts passed. No signing credential, native installer, tag publication, GitHub Pages deployment, or environment-policy mutation was authorized or needed for this local quality pass. | Run the repository release procedure from a matching `v<package version>` tag with authorized credentials when a release is requested. Do not infer deployment success from this pass. |
| External model-quality and device-quality claims remain out of scope. | Browser-local FP32 ONNX execution, cancellation, recovery, bounds, worker ownership, and two production-preview inferences passed. This pass did not establish a new accuracy benchmark across arbitrary user images or hardware. | Keep model-quality measurement explicit and local-model-backed; collect a representative, consented evaluation set before changing quality claims. |
| The usual preview port was occupied by an unrelated process. | The first bounded browser launch recorded the collision. The deciding full suite used isolated port `43210`; no unrelated process was killed. | Continue assigning strict isolated ports in parallel workspaces. This is an environment constraint, not a product failure. |
| Historical replay/server functionality is absent by design. | Every historical commit and hunk has a final disposition. Replay, snapshots, durable delivery, screenshots, bug intake, server/R2 storage, and action streams were intentionally dropped rather than silently approximated. | Reopen those capabilities only through an explicit product-policy decision; do not restore them through compatibility shims or telemetry growth. |
