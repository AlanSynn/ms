Implementation claim

The overlay now uses the existing utils/frameCommitQueue.ts through a small same-file drag-session seam. Pointer moves update the latest same-role target synchronously but queue transient dragging state once per display frame. Pointer-up flushes that latest value before resolving the existing authoritative selection path. Pointer-cancel discards the queued value, clears transient blocker/recovery state, and performs no authoritative commit or rejection mutation. Mechanism identity/type changes, disabled transitions, and reset cleanup cancel pending work through a replay-safe reset path that permits later reuse. Pointer capture remains best effort; click-without-move, candidate filtering, selected/recovery state, and keyboard access remain on the existing paths.
